# Project Management Documentation

This folder contains high-level documentation for the YouSim monorepo architecture and individual modules.

## Documentation Files

- [monorepo-architecture.md](monorepo-architecture.md) - Overview of the monorepo structure and workspace configuration
- [core-module.md](core-module.md) - Documentation for the shared core simulation logic
- [cli-module.md](cli-module.md) - Documentation for the command-line interface
- [api-module.md](api-module.md) - Documentation for the web API service
- [frontend-module.md](frontend-module.md) - Documentation for the React web frontend
- [status.md](status.md) - Current migration status and next steps

## Purpose

These documents serve as reference material for understanding:
- How the monorepo is structured
- What each module does
- How to run and develop each component
- Dependency relationships between packages
